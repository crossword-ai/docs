---
title: "Page suggestions"
description: "A set of prompts placed on a merchant page that open the conversation"
---

Page suggestions put a set of prompts on a merchant page instead of inside the widget. A shopper reading a product page sees "Compare alternatives" or "Is this right for a marathon?" beneath the description, and tapping one opens the conversation with that prompt already sent. It gives shoppers a way into the conversation from the page they are already reading.

## Example

A shopper in the Returning Customer segment opens a product page on a sneaker brand's storefront. Directly below the size selector, a row of two chips reads **Reorder my usual size** and **What's new since my last order**, placed by the Returning Customer Playbook. Tapping **Reorder my usual size** opens the widget with that prompt already sent, and the reply offers the shopper's last size as a quick reply. Everyone else sees the Default Playbook's chips in the same spot: **Find my size** and **Compare alternatives**.

## Anatomy

| Property | What it holds |
| -------- | ------------- |
| Suggestions | The candidate prompts. Each has a label the shopper sees and the message it sends when tapped. |
| Maximum visible | How many prompts show at once. |
| Ranking | The order prompts are considered when more exist than fit. |
| Layout | How the prompts are arranged, such as a row of chips or a stacked list. |
| Fallback set | The prompts shown when the candidates cannot fill the set. |

Prompts can be written in advance or generated at display time from variables such as the product on the page. The prompts belong to the section and embed nothing else from the [Component library](/components/overview). The reply that follows a tap is composed by an Agent and can render any card.

## Where it appears

Page suggestions make the most sense where a shopper is weighing a decision: product pages, near the description or the size selector; collection pages, above the grid; and the cart page, next to the items. Home and about pages work when the prompts are broad, such as "Help me find a shoe".

The set goes into a placement. Insert is the usual action, since a suggestion set rarely replaces an existing part of the page. Read [Pages and placements](/orchestration/pages-and-placements).

## Rules

Page suggestions carry their own rule, scoped by target page and placement. Everything in the shared rule shape applies, though timing and delivery limits are rarely needed because the set usually renders with the page.

- **Target page, placement, and placement action.** Required.
- **Conditions and priority.** Which shoppers see the set, and where it ranks against other sets for the same placement.
- **Timing and delivery limits.** Optional. A delay or a scheduled window, and a frequency cap, suppression, or repeat behavior, for a set you want to show once or only during a campaign.

The component selection by page placement Rulebook picks one set per placement. How many prompts the shopper sees inside the winning set is the set's own maximum visible count, not a Rulebook setting. When no rule matches, the Default Playbook's set shows. If it has none, the placement stays empty.

The shared rule shape is described under [Page sections](/components/page/page-sections). The full list of conditions and how they combine is in [Rules](/orchestration/rules).
