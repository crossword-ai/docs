---
title: "Follow-up suggestion"
description: "Suggested next prompts the Agent writes under each assistant reply"
---

A follow-up suggestion is a prompt a shopper sees directly under an assistant reply. The Agent writes a new set for every reply, based on the reply it just gave and the Journeys that are enabled. Tapping one sends that prompt back to the Agent or takes the shopper into a Journey. Follow-ups carry no rule, no conditions, and no priority, and no Rulebook resolves them.

## What it contains

| Property | What it holds |
| -------- | ------------- |
| Label | The text on the suggestion |
| Action or prompt | What tapping it does. It sends a prompt to the Agent, or starts a Journey |
| Kind | Product Q&A or Journey |

There are two main kinds.

- **Product Q&A follow-ups** are next questions about the product or products in the reply, such as comparing them, sizing, price, or ingredients.
- **Journey follow-ups** take the shopper into a Journey you have built, such as a quiz Journey ("Find my routine") or a support Journey.

A follow-up holds its own label and embeds nothing from the [Component library](/components/overview). A [quick reply](/components/conversation/assistant-reply#quick-reply) is different. It is a closed answer with a fixed value, such as Yes or Size 9, and the Agent composes it into the reply itself.

## How it is configured

You configure follow-ups through the Agent, in its prompt. In the Agent's [instructions](/agents/instructions-and-model), describe when to offer which kind, how many, and which Journeys to point to. On every reply, the Agent reads the reply it just gave and the enabled Journeys, and writes the follow-ups from your guidance. [Response configuration](/agents/response-configuration) turns follow-ups on for the Agent and sets the suggestion set.

Guidance in the Agent's instructions reads like this.

```text
After you recommend products, offer up to three follow-ups:
one to compare them, one about sizing,
and one that starts the quiz Journey if the shopper seems unsure.
After you answer a question about an order, offer the support Journey.
```

There is no rule to write and no list of configured follow-ups to maintain. Which Agent answers, and so whose instructions apply, is decided upstream by the agent routing Rulebook. Read [Routing](/agents/routing).

## Suggestion set

Follow-ups render inside a suggestion set under the reply. The set is a setting on the Agent's follow-ups, not a component of its own. It is the only thing that limits how many follow-ups the shopper sees.

| Setting | What it controls |
| ------- | ---------------- |
| Maximum visible | How many follow-ups show under one reply |
| Layout | How the visible follow-ups are arranged, such as a row of chips or a stacked list |

## Examples

Two kinds of follow-up. Each one describes the guidance, not the exact copy.

### Product Q&A follow-ups

Next questions about the products the Agent just recommended.

```yaml
Configured in: Agent instructions
After: A reply that recommends a few products
Follow-ups: Up to three next steps about those products: see more options, compare them, and narrow by price
```

### Journey follow-ups

Suggestions that move a shopper who asks for help choosing into a guided Journey you have built.

```yaml
Configured in: Agent instructions
After: A reply where the shopper asks for help choosing and has not settled on a product
Follow-ups: Three prompts that narrow the choice, by where the product will go and by value
Takes the shopper to: A guided discovery Journey that asks a few questions and recommends
```
