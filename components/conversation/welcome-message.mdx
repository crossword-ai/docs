The welcome message is the first component a shopper reads when the widget opens. It sits at the top of the conversation, above the conversation starters, before the shopper has typed anything. It is a Conversation component that carries no rule. There is one welcome message per experience, and every shopper sees the same one on every page.

## What it contains

| Property | What it holds |
| -------- | ------------- |
| Content | The message text, with rich text formatting where the channel supports it |
| Media | An optional image or video shown with the message |
| Embedded components | Any card or interactive component from the [Component library](/components/overview), such as a product card or a quiz |

The text, media, and embedded components belong to the welcome message. The cards it embeds are plain components with no rule of their own. They show because the welcome message shows, and the welcome message shows every time the widget opens.

## Where it is set

The welcome message is global. You set it once, in [Global settings](/global/overview), and it carries no rule.

- **One per experience.** Each experience has exactly one welcome message.
- **Set in Global settings.** Journeys do not add welcome messages. Each Journey card shows the global one for reference only.
- **The same for everyone.** Every shopper sees it on every page, in every Journey, whatever the arrival source, segment, device, or cart.

To change what a shopper reads first, edit the welcome message in Global settings. The change applies to every conversation in that experience.

## Greetings that depend on context

A greeting that depends on where the shopper came from or who they are, such as an arrival from a video or an ad, or membership in a segment, belongs in a [proactive message](/components/conversation/proactive-message). A proactive message can appear on arrival, such as "Looking for the pair from the video?" It carries a "shows when" rule, shows inside the active Journey when that rule is met, and routes to a named Agent.

To offer different prompts in different situations, use [conversation starters](/components/conversation/conversation-starter). Starters sit under the welcome message and belong to the active [Journey](/orchestration/journeys), so they change with the page the shopper is on. They do not change with the arrival source or segment.

## Examples

Two ways to configure the one welcome message. Whichever you choose, every shopper sees it.

### Text only

A single line in the store's voice, with starters beneath it.

```yaml
Content: One-line greeting that says what the assistant can help with
Media: none
Embedded component: none
```

### Text with product cards

A personal greeting with a fanned row of picks the shopper can swipe through.

```yaml
Content: Greeting with the shopper's name, a short heading, and a closing line that invites them to explore
Media: none
Embedded component: Product collection, shown as a fanned carousel
```
