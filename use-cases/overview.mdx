The rest of these docs describe one object at a time: a Journey, an Agent, a proactive message. The example journey puts them together into a setup you can read end to end.

[Five Journeys, three Agents](/use-cases/five-journeys-three-agents) is the reference setup. It maps a whole storefront: every Journey with its entry point, starters, proactive messages, Agent, and goals, every Agent with its eleven parts, and the global settings they share. Swap in your own catalog. The structure does not change.

Two ideas hold throughout. A shopper is in one Journey at a time, chosen by entry point, and the Default Journey covers every page nothing else claims. Each starter and each proactive message names the Agent it routes to.
